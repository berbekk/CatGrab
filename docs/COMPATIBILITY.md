# Проверка совместимости CatGrab

Состояние на 2026-11-06. Изменения находятся в рабочей папке и ещё не выпущены.
Минимальная версия остаётся macOS 13. Для сборки нужен SDK macOS 26 или новее.

## Что изменено

- Изменение цветов и содержимого меню не переподключает глобальные клавиши. Повторное сохранение
  того же конфига не пишет файл. Опрос неизменившихся разрешений не обновляет интерфейс.
- Состояние трекпадов защищено от одновременных обращений. Остановка, сон и переподключение
  сбрасывают незавершённые жесты; старые отложенные события не открывают меню.
- Fn отличает физическую клавишу от служебных флагов стрелок. Отпускание HID-хоткея связано
  с исходным нажатием, даже если модификаторы уже изменились. Автоповтор не открывает меню заново.
- Во время записи сочетания глобальные обработчики приостановлены. Esc сохраняет прежнее
  сочетание. Выход из приложения или скрытие окна завершает запись.
- Подстраховка ⌘Tab и ⌘⇧Tab учитывается раздельно. Восстанавливаются только системные сочетания,
  которые CatGrab сам успешно отключил. При сне клавиатурные обработчики освобождаются.
- Новая установка получает ⌃⌥⌘Space вместо ⇧1. Сохранённые сочетания не меняются.
- Повреждённый файл нельзя заменить без успешной резервной копии. Ошибка записи видна в окне;
  изменения остаются в памяти и доступны для экспорта и повторного сохранения. Миграции старых
  настроек сохраняются один раз. Импорт с неверными числовыми кодами клавиш не вызывает падение.
- Окно настроек изменяет размер и возвращается в рабочую область после отключения экрана.
  Длинные настройки прокручиваются отдельно от превью. Названия встроенных меню могут занимать две строки.
- Неактуальные запросы команд отменяются. Поиск пути и запасной поиск по сочетанию делят один
  срок: 0,35 с для команды, 4 с для каталога. Каждый AX-запрос получает не больше оставшегося
  времени и не больше 0,2 с; это ограничение запросов, а не обещание скорости всего меню.

## Что проверено локально

Текущий компьютер: Apple M4, Mac16,13; macOS 27.0.1, сборка 26A434; SDK 26.4.

| Проверка | Результат |
|---|---|
| Исходные автоматические проверки | 155 прошли |
| Проверки после изменений | 182 прошли, ошибок нет |
| Проверка потоков через Thread Sanitizer | 14 проверок ввода прошли; сообщений о гонках нет |
| SwiftLint с `--strict` | Нарушений нет |
| Универсальная сборка | `arm64` и `x86_64`, минимальная macOS 13.0 у обеих частей |
| Структура и подпись приложения | `plutil`, `codesign --verify --deep --strict` проходят |
| Интерфейс | Снимки светлой и тёмной темы, окна 1120×760 и 880×580, длинный список исключений |
| Геометрия окна | Проверены маленькие рабочие области, отрицательные координаты и отключённый экран |
| Необходимые приватные API | Символы SkyLight и MultitouchSupport присутствуют на текущем Mac |

Снимки лежат в `build/review/`. Для них использован отдельный временный процесс с другим
идентификатором приложения, отдельным конфигом и без AppDelegate и глобальных перехватчиков.
Установленный `/Applications/CatGrab.app` не заменялся и не перезапускался.
Сборка для просмотра: `build/CatGrab.app`; подпись ad-hoc, версия пока 1.4.0 из текущего Info.plist.
Запуск этой сборки с тем же идентификатором может потребовать повторной выдачи разрешений macOS.

## Что ещё требует реальных устройств

| Среда | Что подтвердить | Статус |
|---|---|---|
| Intel Mac с macOS 13/14/15 | Запуск, обычные клавиши, Fn при наличии, отсутствие Liquid Glass на старой системе | Не проверено; Rosetta на текущем Mac недоступна |
| Apple silicon с macOS 13/14/15/26 | Запуск, разрешения, обычное оформление и Liquid Glass там, где поддерживается | Не проверено на этих версиях |
| Встроенный и Magic Trackpad одновременно | 3/4/5 пальцев, отсутствие запуска от смахивания, Bluetooth-переподключение | Логика проверена тестами; физические устройства не проверены |
| Сон, пробуждение, внешний экран | Нет зависшего меню; жесты и клавиши возвращаются; окно остаётся целиком доступным | Геометрия проверена; физический цикл не проверен |
| AltTab, Karabiner, BetterTouchTool, Raycast | Только явно назначенные сочетания; возврат системного переключателя после выхода | Сохранение исходного состояния проверено тестами; совместная работа не проверена |
| Поле пароля / Secure Input | ⌘Tab остаётся доступным; ⌘⇧Tab не зависит от регистрации ⌘Tab | Требует проверки настоящих событий |
| VoiceOver, увеличение контраста, уменьшение движения | Понятные названия элементов и доступные действия | Полная проверка не проведена |
| Динамики и Bluetooth-наушники | Нет помех при открытии и выборе секторов | Причина прежней помехи не подтверждена и не объявлена исправленной |

Глобальные сочетания по определению заменяют такое же сочетание в другом приложении.
macOS не предоставляет полного списка чужих перехватчиков. Предупреждение о неудачной регистрации
не доказывает отсутствие всех конфликтов. Особенно это касается одновременно работающих замен ⌘Tab.
MultitouchSupport и SkyLight — приватные API: наличие символов на текущем Mac не гарантирует
их поведение в будущей macOS. При отсутствии нужного API соответствующая интеграция пропускается.

## Воспроизводимые проверки в рабочей папке

Эти команды выполняются локально и не устанавливают приложение:

```bash
swift test
swiftlint lint --strict
swift test --sanitize=thread --scratch-path .build/thread-sanitizer --filter 'TrackpadFrameProcessorTests|HotkeyInputStateTests'
CATGRAB_ARCHS='arm64 x86_64' CODESIGN_IDENTITY=- ./build.sh
lipo -archs build/CatGrab.app/Contents/MacOS/CatGrab
codesign --verify --deep --strict --verbose=2 build/CatGrab.app
xcrun vtool -show-build build/CatGrab.app/Contents/MacOS/CatGrab
```

Для проверки на других Mac рекомендуемый порядок: резервный экспорт текущих настроек, затем
одна проверяемая копия CatGrab, затем клавиатура, жесты, сон и внешний экран. Успешный результат:
каждое нажатие открывает нужное меню один раз, отмена не выполняет команду, после выхода из CatGrab
системные сочетания работают как до его запуска. Сначала проверяется работа без других замен
переключателя, затем с каждой используемой утилитой отдельно. Результаты фиксируются с версией
macOS, моделью Mac, способом вызова меню и названием конфликтующей утилиты, если она есть.
