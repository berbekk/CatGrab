# PieMenu

## Установка

1. Скачайте **PieMenu.dmg** со страницы [Releases](../../releases/latest)
2. Откройте файл и дважды нажмите **Install PieMenu**
3. Если macOS пишет, что установщик «не удалось проверить»: откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите **Открыть все равно**
4. Запустите PieMenu из папки «Программы». Он попросит два доступа — «Универсальный доступ» и «Мониторинг ввода». В обоих случаях нажмите **Открыть системные настройки** и включите переключатель напротив PieMenu. Это нужно для ⌘Tab, Fn и меню активных приложений

Настройки открываются из значка в строке меню или повторным запуском PieMenu из папки «Программы».

Если значка в строке меню нет: в macOS 26 приложение должно быть разрешено в **Системные настройки → Строка меню → Разрешить в строке меню**. PieMenu сам откроет настройки с кнопкой, ведущей в эту панель.

macOS 13 или новее.

## Сборка из исходников

```bash
./install.sh
```

Чтобы выданные доступы не сбрасывались после каждой пересборки, один раз создайте локальный сертификат подписи:

```bash
./scripts/create-dev-signing-identity.sh
```
